# nothingeats-ui

The design system of [NothingEats](https://github.com/slashncode/nothingeats): **soren-ui** base components (React Aria Components, SCSS Modules, CSS custom properties), the **NothingEats theme**, and **food-domain components**. Published as `@slashncode/nothingeats-ui`; the web app and the backoffice import from here only.

```
soren-ui (base components, tokens)         src/soren/      vendored, never edited here
   ▼
NothingEats theme (token overrides, fonts)  src/theme/
   ▼
domain components                           src/components/ RestaurantCard, DishCard, PriceTag, …
```

## Use

```tsx
import type { RestaurantSummary } from '@slashncode/nothingeats-ui';
import { RestaurantCard } from '@slashncode/nothingeats-ui';
import { I18nProvider, RouterProvider } from 'react-aria-components';
import '@slashncode/nothingeats-ui/style.css';

// I18nProvider: language and number/date formats of all components.
// RouterProvider: client-side routing for every React Aria link.
export function Restaurants({ restaurants, navigate, useHref }: Props) {
    return (
        <I18nProvider locale="de-DE">
            <RouterProvider navigate={navigate} useHref={useHref}>
                {restaurants.map((restaurant: RestaurantSummary) => (
                    <RestaurantCard key={restaurant.slug} restaurant={restaurant} href={`/restaurants/${restaurant.slug}`} />
                ))}
            </RouterProvider>
        </I18nProvider>
    );
}
```

- **Dark mode**: the `dark` class on `<html>`.
- **Language**: domain components carry their own German and English strings and follow the nearest `I18nProvider`, like React Aria does. They take catalog data as it comes from `/api/catalog/v1` (already in the user's language).
- **Fonts**: Inter and Bricolage Grotesque, self-hosted through Fontsource (no third-party font requests). The package imports them; the app's bundler serves the files.
- **PostHog**: cards carry `data-ph-capture-attribute-*` (dish id, restaurant slug), so autocaptured clicks say which dish or restaurant it was.

## Develop

```bash
pnpm install
pnpm dev               # Storybook on http://localhost:6006 (toolbar: locale, light/dark)
pnpm test              # every story runs as a test in Chromium, with axe accessibility checks
pnpm lint && pnpm typecheck && pnpm build
```

Accessibility violations fail the tests (`a11y.test: 'error'`); the dark stories check contrast in the dark theme too.

## soren-ui

`src/soren/` and `src/soren-ui.ts` are generated by [`scripts/sync-soren-ui.mjs`](scripts/sync-soren-ui.mjs) from soren-ui's published registry output (`public/r/*.json`) at one commit, recorded in [`SOREN_UI.md`](SOREN_UI.md). Fixes go upstream into soren-ui; then:

```bash
pnpm sync:soren-ui --ref <sha or branch>    # or `just sync-soren-ui` in the hub repo
pnpm check:soren-ui                            # proves src/soren reproduces byte for byte
```

The sync refuses a commit that is not pushed, and a registry whose built JSON is stale against its sources.
